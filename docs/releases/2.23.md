# RID Workbench 2.23 发布说明

同步日期：2026-11-04。

本次将 Mac 交付版的模拟遥测补全功能同步到公开仓库。相比 2.22，固定参数发射可以保存并广播相对高度、航向和水平／垂直速度；单机和多机模式带有明确的模拟精度等级，开始发射时从浏览器获取 UTC 时间。

## 使用变化

1. 固定参数页面新增“飞行状态”。航向以真北为 0°，垂直速度正数表示上升，负数表示下降；固定参数模式不会自动移动坐标。
2. 多机模拟明细显示相对起飞点高度。1 台和 100 台模式共用遥测编码逻辑。
3. 每次网页启动发射都会校时，页面显示校时状态。重启后需要重新校时，手机／电脑时钟和请求延迟仍影响实际时间准确性。
4. 历史保存的身份、坐标和时长可迁移；新增字段有独立默认值。

模拟精度：水平定位 ≤10 m、垂直定位 ≤3 m、速度 ≤1 m/s、时间 ≤0.1 s。未收到或无法提供的信息不会全部伪装成已知值：零坐标时保留未知位置与水平精度，未校时时保留未知时间与时间精度，气压高度仍未知。

## 公开版与设备本地版本

遥测源码、页面和测试来自用户提供的 `RID_Repair_2.23` 交付包；包内 490 项文件的 SHA-256 校验均匹配。交付包页面及地图脚本与此前从设备只读提取的对应内容一致。

交付包附带的额外城市、历史县城和边界数据未完成来源和再分发许可核实。因此本仓库的 `map_picker.h` 沿用 2.22 公开版，并保留其双指／滚轮缩放；本次不发布附加地图数据、包含它们的固件二进制或原始压缩包。原始交付包和实体板内地图均未修改。

这不是设备本地固件的逐字节复刻。README 中的编译步骤构建的是本仓库公开版；地图内容与设备本地版本不同。

模拟运动保持交付版和公开版原有的均匀分散及连续周期轨迹，未在这次源码同步中重做随机运动或间歇悬停。
