# RID 工作台电脑端 2.20

电脑端通过 Wi-Fi 访问 ESP32 的 `http://192.168.4.1/`；USB 连接用于供电和检测插拔，不传输网页或控制指令。热点名称和密码沿用设备设置。离线使用无需互联网，但电脑仍须连接设备 Wi-Fi。地图可用范围取决于固件中实际提供的离线地图数据。

## macOS

1. 先在 macOS 运行 `macos/build.sh` 生成“RID工作台.app”，再将其复制到“应用程序”或其他固定目录并双击打开。此应用为本机编译、未签名、未公证，macOS 可能要求在“系统设置 → 隐私与安全性”中明确允许打开。
2. 点击“开启登录后自动监听”。以后登录电脑时客户端在后台运行；识别到 ESP32-S3 设备插入后会自动弹出并打开设备页面。移动应用后请重新打开应用，先关闭再开启自动监听，以更新路径。关闭窗口会隐藏到后台；要完全退出请选择系统菜单中的“退出 RID工作台”。
3. 将电脑连接到设备 Wi-Fi，点击“打开设备页面”。如页面未加载，检查热点连接，然后再次点击。也可使用“浏览器打开”。
4. 不再需要后台监听时，点击“关闭登录后自动监听”，然后退出应用。

该包在 Apple Silicon macOS 构建；Intel Mac 上可使用 Xcode 命令行工具运行 `macos/build.sh` 重新编译。构建需要 Swift、AppKit、WebKit、IOKit，不需要第三方依赖。

## Windows

1. 双击 `windows/安装并开启自动监听.bat`。脚本使用系统 .NET Framework 编译 `RIDClient.cs`，在当前用户的本地应用目录生成客户端，并添加当前用户登录启动快捷方式；不会安装驱动或更改系统级设置。
2. 客户端会监听设备插入、弹出窗口并调用默认浏览器打开设备页面。电脑须连接设备 Wi-Fi。手动使用时也可以点击“打开设备页面”。关闭窗口后客户端会留在系统托盘，双击托盘图标或右键选择“打开 RID 工作台”可重新显示窗口；右键菜单也可打开设备页面或退出监听。
3. 双击 `windows/关闭自动监听.bat` 可移除登录启动快捷方式。打开客户端后点击“退出监听”可结束当前运行；如需删除程序，可删除 `%LOCALAPPDATA%\RIDWorkbench`。

Windows 客户端源码和安装脚本已提供，需在 Windows 电脑上编译，当前没有经过 Windows 实机验证或预编译 EXE。脚本需要系统 .NET Framework C# 编译器、Windows Management Instrumentation 和 PowerShell，执行受限的电脑可能需要管理员调整相应策略。

## 识别范围与限制

自动监听只读取 USB 设备的 VID/PID，匹配 `303A:1001`（ESP32-S3 原生 USB Serial/JTAG），不会打开串口或向设备发送命令。该 VID/PID 能识别一类 ESP32-S3，不能证明插入的是本项目的板子；其他使用相同 VID/PID 的设备也可能触发弹窗。使用 USB 转串口芯片或不同 USB 配置的板子可能不会触发弹窗，仍可手动打开页面。客户端必须事先安装并在后台运行；操作系统不会让一个刚插入的普通串口设备自行安装或自动启动应用。
